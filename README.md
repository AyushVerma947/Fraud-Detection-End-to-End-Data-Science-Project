# 🚨 Fraud Detection – End-to-End Data Science Project

This repository demonstrates a complete end-to-end Data Science workflow using a Fraud Detection use case.  

The project demonstrates the complete **Data Science Lifecycle** using a Fraud Detection case study, including:

- Data Exploration
- Data Cleaning
- Visualization
- Supervised Learning
- Handling Class Imbalance (SMOTE)
- Outlier Detection (DBSCAN)
- Time Series Forecasting (Healthcare)

## 📥 Dataset Download Instructions

⚠️ Datasets are not included in this repository due to size limitations.  
Please download them from Kaggle and place them inside the `data/` folder.

---

### 1️⃣ Online Fraud Detection Dataset

Download from:  
https://www.kaggle.com/datasets/jainilcoder/online-payment-fraud-detection

Steps:
- Extract the dataset
- Rename to `online_fraud.csv` (if needed)
- Place inside `Fraud Detection/data/`

---

### 2️⃣ COVID-19 Time Series Dataset

Download from:  
https://www.kaggle.com/datasets/niketchauhan/covid-19-time-series-data
